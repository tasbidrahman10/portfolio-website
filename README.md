# Tasbid Al Rahman Portfolio

Personal portfolio website for Tasbid Al Rahman, built with React, TypeScript, Vite, Tailwind CSS, Motion, and Lucide icons.

## Local Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Run TypeScript validation:

```bash
npm run lint
```
